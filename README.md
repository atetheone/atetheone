# Hi, I'm Aristide 👋

Software engineer in Dakar. I spend most of my time on backend systems that move money: payment integrations, mobile money, and USSD services that let people bank from any phone, even without internet. Plus the unglamorous work of making sure a retry never charges anyone twice.

Lately I've been having a lot of fun building AI skills: turning the repetitive parts of my work into instructions an AI assistant can follow, so I spend less time on boilerplate and more on the interesting problems. The fun part is testing what comes out until I can actually trust it.

## Tools I use

- **Languages:** Python, TypeScript, JavaScript, Java
- **Backend:** Flask, Node.js, NestJS, Express, Spring Boot
- **Frontend:** React, Angular
- **Data:** PostgreSQL, MySQL, Redis, MongoDB, SQLite
- **Infra:** Docker, Kubernetes, Helm, GitHub Actions, AWS
- **Testing:** Pytest, Vitest, Postman, K6
